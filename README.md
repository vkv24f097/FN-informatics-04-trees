## Задание 1
Реализуйте класс бинарного дерева поиска.
Описание бинарного дерева поиска можно найти в книге Кормена "Алгоритмы. Построение и анализ (3-е издание)", стр 319, глава 12. Методы класса описаны ниже.

```cpp
template <class T>
class Tree {
public:
  struct Node {
    Node* Left;
    Node* Right;
    T Value;
  };

  BinarySearchTree();
  ~BinarySearchTree();

  void Add(const T&);
  Node* Find(const T&);
  void Remove(Node*);
};
```
В данном задании были применены следующие методы:
Структура Node представляет узел дерева с указателями на левого и правого потомка и значением.

Конструктор `BinarySearchTree()` инициализирует корень дерева как nullptr.

Деструктор `~BinarySearchTree()` рекурсивно удаляет все узлы дерева.

Метод `Add` добавляет новый элемент в дерево, сохраняя свойства BST.

Метод `Find` ищет узел с заданным значением.

Метод `Delete` удаляет указанный узел из дерева.

**Вспомогательные приватные методы:**

`DestroyTree` - рекурсивно удаляет узлы

`AddNode` - рекурсивно добавляет узел

`FindNode` - рекурсивно ищет узел

`FindMin` - находит минимальный узел в поддереве

`DeleteNode` - рекурсивно удаляет узел с заданным значением

Код реализует свойства бинарного дерева поиска, где для каждого узла:

- элементы левого поддерева меньше значения узла

- элементы правого поддерева больше или равны значению узла



## Задание 2

Использованы:

## Задание 3

Реализация кастомной функции `Поиск медианы в BST`:

**Условие**: Напишите метод `T median()`, находящий медиану (средний элемент) для BST с нечётным числом узлов.  <br>
**Оптимизация**: Используйте метод двух указателей без полного обхода.

Использованы:
- `BSTNode` - класс узла дерева с данными и указателями на левого и правого потомка
- `BST` - класс бинарного дерева поиска с корневым узлом и счетчиком размера
**Метод `median`():**
 - [] Проверяет, что дерево не пустое и имеет нечетное количество узлов
 - [] Вычисляет позицию медианы (size/2 + 1)
 - [] Использует рекурсивный in-order обход с подсчетом пройденных узлов
 - [] Возвращает данные узла, когда счетчик достигает позиции медианы
  
**Касательно оптимизации:**
- Не сохраняет все элементы дерева, а только считает их
- Прекращает поиск сразу после нахождения медианы
- Использует O(1) дополнительной памяти
